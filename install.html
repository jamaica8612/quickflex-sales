Beta 1.04 APK 받기 릴리스 정보

기존 버전을 업데이트할 때는 앱을 삭제하지 말고 새 APK를 그대로 설치하세요.

시작 전 확인
  • 이 페이지의 공식 릴리스 APK만 사용합니다.
  • 플렉스노트 PWA에서 승인된 계정으로 로그인할 수 있어야 합니다.
  • 메뉴 이름은 Android 버전과 제조사에 따라 조금 다를 수 있습니다.

APK를 내려받아 엽니다

위의 Beta 1.04 APK 받기를 누릅니다. 다운로드가 끝나면 알림이나 내 파일의 다운로드 목록에서 APK를 여세요.

요청될 때만 이 출처를 허용합니다

Chrome이나 내 파일에서 처음 APK를 열면 설치 권한 안내가 나올 수 있습니다.

설정 → 이 출처 허용 → 뒤로 → 설치

설치가 끝난 뒤에는 같은 화면에서 이 출처 허용을 다시 꺼도 됩니다.

갤럭시에서 보안 위험 자동 차단 안내가 나올 때

일부 갤럭시·One UI 버전에서는 별도의 보안 위험 자동 차단 기능이 외부 APK 설치를 막을 수 있습니다. 이 메시지가 실제로 나타날 때만 화면에 표시된 보안 설정을 확인하세요.

메뉴 이름과 위치는 기종·One UI 버전에 따라 달라 실제 기기 화면을 우선합니다. 설치 후에는 변경한 보호 기능을 다시 켜세요.

Play 프로텍트 검사를 확인합니다

Google Play 외부에서 받은 앱이라 검사 권장이나 경고가 표시될 수 있습니다. 앱 검사가 보이면 먼저 검사를 진행하고 결과를 확인하세요.

설치가 차단될 때: Play 프로텍트 해제 방법

공식 릴리스 APK가 맞는지 확인한 뒤에도 설치가 완전히 차단되는 경우에만 Play 프로텍트 검사를 잠시 해제합니다.

Play 스토어 → 프로필 사진 → Play 프로텍트 → 설정 → Play 프로텍트로 앱 검사 끄기

APK 설치가 끝나면 같은 경로에서 Play 프로텍트로 앱 검사를 바로 다시 켜세요.

Google은 보안을 위해 Play 프로텍트를 항상 켜 둘 것을 권장합니다. 평소에는 해제하지 마세요.

Google 공식 Play 프로텍트 안내 보기

접근성 켜기가 막히면 제한된 설정을 허용합니다

Android 13 이상에서는 외부에서 설치한 앱의 접근성 설정이 제한될 수 있습니다. 접근성 화면에서 제한 안내가 나올 때만 진행하세요.

설정 → 앱 → 플렉스노트 → 오른쪽 위 더보기 ⋮ → 제한된 설정 허용

플렉스노트가 쿠팡플렉스 화면의 완료 수량을 읽으려면 접근성이 필요합니다. 공식 릴리스 APK가 아닌 앱에는 제한된 설정을 허용하지 마세요.

플렉스노트 데이터 연결을 켭니다

설정 → 접근성 → 설치된 앱 또는 설치된 서비스 → 플렉스노트 데이터 연결 → 사용

확인 창이 나오면 읽기 범위를 확인하고 허용합니다. 플렉스노트는 쿠팡플렉스 화면의 접근성 정보에서 배송 진행·완료 수량을 읽습니다.

첫 업무를 시작합니다

  1. 플렉스노트에서 PWA와 같은 승인 계정으로 로그인합니다.
  2. 쿠팡플렉스 배송 화면에서 최신 완료 가구·상품수가 표시되게 합니다.
  3. 플렉스노트의 배송 측정 메뉴에서 날짜·구역을 확인하고 측정 앱 열기를 누릅니다.
  4. 구역을 다시 확인한 뒤 업무 시작을 누릅니다.
  5. 페이스를 잴 구간에만 측정 시작을 누릅니다. 배송 중 수량은 자동으로 읽습니다.
  6. 1차 배송이 끝나면 측정 종료를 누릅니다.
  7. 배송이 모두 끝나면 최신 완료 수량을 표시한 뒤 업무 종료에서 구역·수량을 검토하고 저장합니다.

설정이 끝났습니다
