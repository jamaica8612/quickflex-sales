설치

APK를 받고 설치합니다

APK를 내려받아 엽니다

위의 Beta 1.05 APK 받기를 누릅니다. 다운로드가 끝나면 알림이나 내 파일의 다운로드 목록에서 APK를 여세요.

처음 설치할 때는 확인 창에서 설치를 누릅니다. 기존 사용자는 앱을 삭제할 필요 없이 같은 APK를 열어 업데이트할 수 있습니다.

요청될 때만 이 출처를 허용합니다

Chrome이나 내 파일에서 처음 APK를 열면 설치 권한 안내가 나올 수 있습니다.

설정 → 이 출처 허용 → 뒤로 → 설치

설치가 끝난 뒤에는 같은 화면에서 이 출처 허용을 다시 꺼도 됩니다.

갤럭시에서 “안전하지 않은 앱” 경고가 나올 때

삼성 설치 화면에서 “안전하지 않은 앱” 경고가 별도로 표시될 수 있습니다. 이 경고는 Google Play 프로텍트 화면과 다르므로 같은 안내로 보지 마세요.

먼저 바텀시트에서 경고 내용을 확인합니다. 무시하고 설치를 선택하면 인증되지 않은 출처와 개인정보 접근 위험을 설명하는 상세 화면이 한 번 더 나타납니다. 필요한 권한만 허용할지 검토한 뒤 상세 화면에서 다시 선택해야 설치가 진행됩니다.

바로 진행하지 말고 이 페이지의 공식 릴리스 APK인지 먼저 확인한 뒤 두 경고의 내용을 모두 검토하세요. 메뉴와 경고 문구는 기종·One UI 버전에 따라 달라 실제 기기 화면을 우선합니다.

Play 프로텍트 검사를 확인합니다

Google Play 외부에서 받은 앱이라 검사 권장이나 경고가 표시될 수 있습니다. 앱 검사가 보이면 먼저 검사를 진행하고 결과를 확인하세요.

설치가 차단될 때: Play 프로텍트 해제 방법

공식 릴리스 APK가 맞는지 확인한 뒤에도 설치가 완전히 차단되는 경우에만 Play 프로텍트 검사를 잠시 해제합니다.

Play 스토어 → 프로필 사진 → Play 프로텍트 → 오른쪽 위 설정 → Play 프로텍트로 앱 검사 끄기 → 일시중지 → 지문 또는 PIN 인증(표시될 때)

확인 창에는 일시중지·사용 중지·취소가 표시될 수 있습니다. 일시중지를 선택하면 다음 날 검사가 자동으로 다시 켜집니다.

APK 설치가 끝나면 다음 날까지 기다리지 말고 같은 경로에서 Play 프로텍트로 앱 검사를 즉시 다시 켜세요.

Google은 보안을 위해 Play 프로텍트를 항상 켜 둘 것을 권장합니다. 평소에는 해제하지 마세요.

연결

배송 완료 수량을 읽도록 허용합니다

막힐 때만 제한된 설정을 허용합니다

Android 13 이상에서는 외부에서 설치한 앱의 접근성 설정이 제한될 수 있습니다. 접근성 화면에서 제한 안내가 나올 때만 진행하세요.

설정 → 앱 → 플렉스노트 → 오른쪽 위 더보기 ⋮ → 제한된 설정 허용

플렉스노트가 쿠팡플렉스 화면의 완료 수량을 읽으려면 접근성이 필요합니다. 공식 릴리스 APK가 아닌 앱에는 제한된 설정을 허용하지 마세요.

앱 정보에 오른쪽 위 메뉴가 없을 때

Galaxy A34에서는 접근성 사용을 한 번 시도한 뒤에 제한된 설정 허용 메뉴가 나타났습니다.

설정 → 접근성 → 설치된 앱 → 회색으로 표시된 플렉스노트 데이터 연결 → “앱의 액세스가 거부됨” 확인 → 설정의 앱 정보에서 플렉스노트를 다시 열기 → 오른쪽 위 더보기 ⋮

제한된 설정 허용을 누른 뒤 지문 또는 PIN 인증이 표시되면 기기 인증을 완료하세요.

플렉스노트 데이터 연결을 켭니다

설정 → 접근성 → 설치된 앱 또는 설치된 서비스 → 플렉스노트 데이터 연결 → 사용

확인 창이 나오면 읽기 범위를 확인하고 허용합니다. 플렉스노트는 쿠팡플렉스 화면의 접근성 정보에서 배송 진행·완료 수량을 읽습니다.

화면 예시는 Galaxy A34 · Android 16 기준입니다. 기기와 Android 버전에 따라 메뉴 이름과 순서가 달라질 수 있습니다.

사용

승인된 계정으로 첫 업무를 시작합니다

계정과 업무를 확인합니다

설치와 접근성 설정만으로 측정 기능이 열리지는 않습니다. 같은 계정에 가입 승인과 베타 측정 허용이 모두 필요합니다.

  1. 플렉스노트에서 PWA와 같은 승인 계정으로 로그인합니다.
  2. 쿠팡플렉스 배송 화면에서 최신 완료 가구·상품수가 표시되게 합니다.
  3. 플렉스노트의 배송 측정 메뉴에서 날짜·구역을 확인하고 측정 앱 열기를 누릅니다.
  4. 구역을 다시 확인한 뒤 업무 시작을 누릅니다.

측정 구간과 하루 업무를 구분합니다

  1. 페이스를 잴 구간에만 측정 시작을 누릅니다. 배송 중 수량은 자동으로 읽습니다.
  2. 1차 배송 같은 측정 구간이 끝나면 측정 종료를 누릅니다. 이때는 페이스 구간만 기기에 저장됩니다.
  3. 하루 배송이 모두 끝나면 최신 완료 수량을 표시한 뒤 업무 종료에서 구역·수량을 검토하고 저장합니다.
