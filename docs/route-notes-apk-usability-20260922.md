# 구역노트 모바일 사용성 수정

시안 승인 후 구현한 변경입니다. 운영 배포, 데이터 변경, APK 설치는 하지 않았습니다.

## 동작

- 구역 선택 전에는 검색·내 구역·전체·즐겨찾기 목록을 표시합니다. 지도를 선택할 때 처음 준비합니다.
- 선택한 구역의 경계와 해당 구역의 팁 핀만 표시합니다. 구역 경계가 없는 경우에도 저장된 팁 위치는 표시합니다.
- 선택 직후에는 144px 요약과 `메모 보기`·`구역 변경` 버튼을 표시합니다. 메모를 펼치거나 다시 닫아도 지도 위치를 유지합니다.
- 작성자와 본인 수정 권한을 유지합니다. 구역 참고 사진은 메모 뒤에서 펼쳐 봅니다.
- 작성 중 `위치 선택`으로 지도를 펼치고 `작성 계속`으로 돌아와도 기존 입력과 사진 선택은 같은 폼에 유지됩니다.
- 취소·뒤로 가기는 저장하지 않은 변경을 확인합니다. 화면 높이가 바뀌면 패널 높이를 다시 계산합니다.
- 지도 실패 시 메모 사용은 유지하며 `지도 다시 시도`를 제공합니다.

## APK 연동

PWA가 실제 화면 전환 이후 `set_route_notes_active` 메시지와 `active` 불리언을 전달합니다. 닫기 확인을 거절하면 네이티브 상태도 유지합니다. 로그아웃·계정 상태 초기화에서는 해제하고, 앱 복귀 때 다시 동기화합니다.

Android 변경은 `C:\work\quickflex-finish-review-20260921`, 커밋 `b13d7d0`에 있습니다. 승인된 원본 페이지의 main-frame 브리지에서만 메시지를 받고, 구역노트가 활성 상태이면 `SwipeRefreshLayout`을 비활성화합니다. 다른 탭과 새 페이지에서는 기존 동작을 복구합니다. 측정·집계·업무 세션 로직은 변경하지 않았습니다.

지도는 기존 WebView 안의 네이버 JavaScript 지도입니다. Android 지도 SDK로 변경하지 않았습니다. 당겨 새로고침 차단은 PWA와 APK 업데이트가 모두 필요합니다. 현재 버전 표기와 서비스 워커 캐시 키는 배포 준비 단계에서 올려야 합니다.

## 검증

- 웹 기존 전체 Node 테스트 382개 통과, 실패·건너뜀 0개. 추가한 `route-notes-ui.test.mjs`의 최종 컨트롤러 회귀 검사 6개도 통과했습니다. 선택 구역만 표시, 작성 폼 접기·화면 높이 변경 후 입력 보존, 저장 후 재조회, 취소 거절 시 초안 유지, 뒤로 가기 포커스, 지도 재시도를 검증합니다.
- Android `testDebugUnitTest assembleDebug` 및 `compileDebugAndroidTestKotlin` 성공. JUnit 결과 총 1,369개 중 1,360개 통과, 9개 건너뜀, 실패·오류 0개.
- 예시 데이터 브라우저에서 384×760 구역 선택·메모 펼침·작성자별 수정 버튼을 확인했습니다. 메모 작성→지도 펼침→작성 복귀에서 입력이 보존됐고, 384×420으로 줄인 화면에서도 저장 버튼이 하단 메뉴 위에 배치됐습니다. 가로 넘침이 없습니다.
- 실제 네이버 지도는 로컬 도메인 검증에 사용하지 않았습니다. 지도 선택·핀·범위·공유 페이지 호환성은 지도 어댑터 회귀 검사로 검증했습니다.
- 연결된 Android 기기가 없어 실제 APK 제스처·한글 키보드·사진 선택은 미검증입니다. 브라우저 화면 캡처와 취소 확인창 후속 조작은 자동화 도구 시간 초과로 완료하지 못했습니다.

실제 배포 전 PWA 캐시 버전, APK 버전·서명, 기존 설치 앱 업데이트와 현장 기기 터치 동작을 확인해야 합니다.
