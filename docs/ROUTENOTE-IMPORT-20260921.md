## 원본 보존과 사진

원본의 소프트 삭제 기록까지 포함해 305개 행을 `quickflex_notes_private.import_records`에 보관했다. 전체 원본 JSON은 일반 회원·익명 클라이언트가 읽을 수 없고, 공개 테이블의 `source_record`에는 원본 사진 URL이나 계정 정보를 넣지 않는다. 구역 색상, 도형의 추가 속성, 팁 태그·검증 시각도 보존했다.

동선 1개와 동선 포인트 25개는 원본 기록 보관에 포함했지만, 동선 편집 UI와 별도 농산물시장 화면은 이번 PWA 기능 범위에 포함하지 않는다.

사진은 원본 public URL을 표시하는 대신 `quickflex-route-notes-photos`와 `quickflex-route-note-zone-photos`의 private 객체로 복사했다. 기존 원본 파일은 그대로 유지한다. 70개, 총 110,004,339바이트를 복사하고 각 원본·대상 파일의 SHA-256이 같은지 확인했다. 두 대상 bucket의 public URL 접근이 차단되는 것도 확인했다.

## 도구와 검증

- `scripts/routenote-import-plan.mjs`: 원본 JSON 검사, 계정/ID 대응, 비공개 원본 보관 SQL 생성. 대상에 기존 행이 있으면 덮어쓰지 않고 내용을 비교하며, 차이가 있으면 트랜잭션 전체를 중단한다.
- `scripts/routenote-copy-media.mjs`: 운영자 환경 변수의 service key로만 파일 복사. 덮어쓰기를 금지하고 기존 객체도 원본 해시와 비교한다. 키는 로그·결과 파일·브라우저에 저장하지 않는다.
- 실제 내보낸 데이터로 PGlite 이관을 두 번 실행해 중복 없는 재실행을 검증했다.
- 원격 적용 후 구역/팁/사진 수, 원본 여섯 테이블과 private 보관본의 정렬된 JSON 해시가 모두 일치했다.
- 승인된 계정으로 실제 RLS 읽기: 구역 36개, 팁 138개, 사진 70개. 같은 계정의 import 권한과 원본 archive SELECT 권한은 false, 익명의 팁 테이블 SELECT 권한도 false였다.
- Supabase Security Advisor에서 새 기능의 경고는 없었다. private 원본 보관 테이블의 RLS-without-policy INFO는 의도한 일반 사용자 접근 차단이며 기존 서비스 경고는 이번에 변경하지 않았다.

## 배포 상태

`company_route_notes`, `route_note_import_provenance` 두 DB 마이그레이션과 데이터·사진 복사를 적용했다. 이후 사용자의 배포 승인에 따라 `route_note_shares` 마이그레이션과 공유 Edge Function도 운영에 반영했다. 메뉴·내 구역 필터·스타일·공유 화면은 PWA 1.0.82 릴리스에 포함한다. Android Beta 1.19와 기존 매출·측정 로직은 변경하지 않는다. 세 마이그레이션 파일명은 실제 원격 적용 이력의 버전과 일치하도록 정리했다.
