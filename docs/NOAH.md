# 노아

플렉스노트의 로그인한 사용자용 AI입니다. Supabase Edge Function `noah`에서 OpenAI Responses API의 `gpt-6-luna`를 호출합니다. `OPENAI_API_KEY`는 Edge Function Secret에만 등록합니다.

## 조회와 변경

- 본인의 매출·배송 완료 기록, 날짜별 수정, 단가, 지출·환불·재입금, 일상 점검, 프로필과 소속 회사의 구역·배송 팁·즐겨찾기를 조회합니다. 사용자 JWT, 승인 상태, 명시적 소유자 조건과 기존 RLS를 함께 적용합니다.
- 정산 요약은 앱과 같은 계산 규칙으로 서버에서 집계합니다. 월 정산은 전월 26일~해당 월 25일입니다. 불완전한 원장이나 조회 실패를 전체 합계로 표시하지 않습니다.
- 지출 추가·수정·휴지통 이동, 월 매출 목표, 구역 현재 단가 변경을 제안할 수 있습니다. 자동 배송 원장, 과거 단가 스냅샷, 계정 권한은 변경하지 않습니다.
- AI에는 변경을 실행하는 도구가 없습니다. 서버에 저장된 10분 유효 제안의 이전/변경 값을 보여 준 뒤 사용자가 **확인 후 적용**을 눌러야 반영됩니다. 대화로 “응”이라고 답해도 실행하지 않습니다.
- 확인 RPC는 소유자·승인·만료·기존 값 변경을 다시 검사하고 하나의 트랜잭션으로 적용합니다. 같은 제안을 재확인해도 중복 실행하지 않습니다. 취소는 업무 데이터를 변경하지 않습니다.

## 데이터와 운영

질문에 필요한 조회 결과는 OpenAI로 전달됩니다. Responses API에는 `store: false`를 설정합니다. 이 설정이 제공자의 모든 보관 정책을 대체하지는 않습니다. 대화 이력은 현재 화면 메모리에만 유지하며 새 대화·로그아웃·계정 전환 때 비웁니다. 변경 제안과 사용량은 접근이 제한된 DB 스키마에 저장합니다.

AI 요청은 사용자별 분당 10회, 한국 날짜 기준 하루 100회로 제한합니다. 도구 호출·문맥·출력·응답 시간에도 상한이 있습니다. 확인과 취소는 AI 사용량 제한과 별개입니다.

배포 순서는 `20260924001910_quickflex_noah_confirmed_actions.sql`만 적용 → `noah` 함수 배포 → PWA 배포입니다. 공유 Supabase 프로젝트의 다른 마이그레이션이나 함수는 함께 배포하지 않습니다. JWT 검증을 유지하고 `noah/index.ts`에서 사용자와 승인 상태를 추가 검증합니다.

로컬 회귀 검증은 `node --test tests/noah-*.test.mjs`입니다. SQL 테스트는 격리된 PGlite DB에서 실제 기존 지출 RPC와 새 마이그레이션을 실행합니다. `tests/fixtures/noah.html`은 실제 계정에 연결하지 않는 화면 검증용 모의 응답입니다.
