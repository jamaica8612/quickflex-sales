설치·권한 설정 안내 보기 (새 창)

화면 조작과 수량 확인은 안전하게 정차한 뒤 해주세요.

1

오늘 일할 날짜와 구역을 확인하세요

플렉스노트 매출관리 웹에서

  1. 달력에서 근무 날짜와 등록된 구역을 확인하세요.
  2. 배송 측정 메뉴를 열고 근무표 날짜와 구역이 맞는지 확인하세요.
  3. 측정 앱 열기를 눌러 Android 앱으로 이동하세요.

야간 근무는 자정을 넘길 수 있어요. 달력의 근무일과 일치하는지 확인하고, 다르면 날짜를 직접 바꿔 주세요.

2

쿠팡플렉스에서 배송목록을 열어주세요

업무 시작 전, 현재 배송 상태를 읽는 단계예요

쿠팡플렉스 배송목록 화면을 열어주세요

지도 화면이 아니라, 위쪽에 진행 · 완료 · 미완 수량이 함께 보이는 화면이에요.

  1. 쿠팡플렉스 앱을 열어 주세요.
  2. 아래 메뉴에서 배송목록을 눌러 주세요.
  3. 위쪽 수량이 표시된 것을 확인한 뒤 플렉스노트로 돌아오세요.
이럴 때도 배송목록을 열어주세요수량을 다시 확인하라는 안내가 나올 때, 다음 차수 배송을 시작할 때, 하루 업무를 끝내기 전에 같은 화면을 열어 주세요.
3

업무를 시작하고, 타수 측정을 켜세요

플렉스노트 Android 앱에서

  1. 날짜와 구역을 다시 확인한 뒤 업무 시작을 눌러 주세요.
  2. 배송 페이스도 보고 싶다면 측정 시작을 눌러 주세요.
  3. 쿠팡플렉스로 돌아가 평소처럼 배송하고 완료 처리하세요.
먼저 하루 업무 시작
업무 시작
이어서 페이스 측정
측정 시작
큰 숫자는 ‘이 폰의 배송 페이스’예요시간당 몇 가구를 완료했는지 보여줘요. 차량 주행 속도가 아니며, 함께 일하는 다른 폰의 완료 횟수와는 다를 수 있어요.

측정 앱을 계속 띄워둘 필요는 없어요. 쿠팡플렉스 화면에서 배송을 진행하면 읽힌 완료 정보를 바탕으로 수량과 구역을 집계해요.

구역을 바로 찾지 못한 상품은 확인할 항목으로 남을 수 있어요. 하루 업무를 마칠 때 실제 구역과 수량을 확인해 주세요.

4

1차 배송만 끝났다면 ‘측정 종료’

측정 종료와 업무 종료는 달라요

물건을 다시 싣고 다음 차수 배송을 할 예정이라면, 하루 업무까지 끝내지 마세요.

1차 배송을 마치고, 다음 배송이 남았을 때

측정 종료

이번 구간의 타수 측정을 마치고 측정 기록을 저장해요.

하루 업무는 계속 이어져요

오늘 예정된 배송을 모두 마쳤을 때

업무 종료

구역과 수량을 검토하고, 최종 기록을 매출에 반영하며 마무리해요.

하루 업무를 마치는 단계예요

다음 차수 배송을 시작할 때
쿠팡플렉스 배송목록 열기 → 플렉스노트로 돌아오기 → 측정 시작

너무 짧거나 변화가 없는 측정은 기록이 저장되지 않을 수 있어요. 종료 후 앱의 안내를 확인해 주세요. ‘측정 종료’만 눌렀다고 하루 매출 기록이 끝난 것은 아니에요.

5

마지막 수량을 확인하고 업무를 종료하세요

자동 집계한 내용도 저장 전에 한 번 확인해 주세요

종료 전에도, 쿠팡플렉스 배송목록 화면을 열어주세요

현재 진행·완료·미완 수량이 표시된 뒤 플렉스노트로 돌아와 업무 종료를 눌러 주세요.

저장된 배송 정보를 다시 확인한 뒤 업무 종료 화면이 열려요. 다음 내용을 차례로 살펴보세요.

구역과 상품 수

316C · 316D처럼 오늘 일한 구역이 모두 있는지, 각 구역의 수량이 맞는지 확인하세요. 세부 코드는 그대로 표시돼요.

프레시백 · 반품 · 취소

오늘 처리한 수량과 비교하세요. ‘취소 포함’, ‘반품 별도’ 등 화면에 적힌 구분도 함께 확인해 주세요.

예상한 구역 · 못 찾은 구역

예상은 확정이 아니에요. 확인이 필요한 상품이 있다면 실제 배송한 구역으로 맞춰 주세요.

숫자가 다르면 ‘수량 수정’수량을 고친 뒤 완료를 눌러 검토 화면으로 돌아오세요. 여기의 ‘완료’는 수정 마침이며, 마지막 저장은 아래 버튼으로 해요.

수량 차이나 필수 입력 경고가 있으면 그 안내를 먼저 확인해 주세요. 경고가 남은 상태를 정상 저장 완료로 생각하지 마세요.

확인이 끝났다면 ‘매출에 기록하고 종료’

최종 버튼을 누른 뒤 저장 결과 안내까지 확인해 주세요. ‘기록 없이 강제 종료’는 정상 저장 버튼이 아니에요.

6

달력에서 오늘의 매출 기록을 확인하세요

플렉스노트 매출관리 웹으로 돌아와서

  1. 업무를 저장한 날짜의 기록 화면을 열어 주세요.
  2. 구역별 건수와 단가, 매출이 맞는지 확인해 주세요.
  3. 잘못 입력한 값이 있다면 수정하고 저장을 눌러 주세요.
단가나 저장 결과를 확인해 주세요단가 입력 안내가 나오면 실제 적용할 단가를 입력하세요. 저장에 실패했다는 안내가 나왔다면, 달력의 기록 화면에서 반영 여부를 확인한 뒤 필요한 수량을 기록해 주세요.

배송 건수만 확인하지 마세요

날짜, 주간·야간 구분, 구역별 단가가 모두 맞아야 원하는 매출로 기록돼요.

수정 후에는 저장까지

입력창의 숫자를 바꾸는 것과 저장하는 것은 달라요. 최종 저장 결과를 확인해 주세요.

자주 헷갈리는 점

‘수량을 다시 확인해 주세요’라고 나와요.

쿠팡플렉스 배송목록 화면을 열어주세요. 위쪽에 진행·완료·미완 숫자가 보이는지 확인한 뒤 플렉스노트로 돌아오세요.

계속 읽히지 않는다면 접근성 설정을 확인해 주세요. 종료 시점에도 수량이 다르다면 업무 종료 화면에서 실제 수량을 검토해 주세요.

쿠팡플렉스 숫자와 이 폰의 숫자가 달라요.

플렉스노트의 페이스는 이 폰에서 완료 처리한 기준이에요. 같은 계정으로 두 사람이 배송하거나 같은 집을 다시 방문하면, 쿠팡플렉스의 누계와 기준이 달라질 수 있어요.

숫자가 다르다는 이유만으로 누락이라고 단정하지 말고, 업무 종료 화면에서 실제 구역별 수량을 확인해 주세요.

스캔 후 배송한 상품의 구역을 못 찾았어요.

배송 완료를 읽어도 구역을 연결할 정보가 부족할 수 있어요. 업무 종료 때 저장된 배송 정보로 다시 확인하지만, 모든 구역을 찾는 것은 아니에요.

‘예상’이나 ‘못 찾음’으로 남은 항목은 실제 배송한 구역을 확인하고 최종 수량을 맞춰 주세요.

앱이 구역을 예상했다고 하면 그대로 저장해도 되나요?

실제로 배송한 구역과 맞는지 먼저 확인해 주세요. 예상 결과는 확인을 돕는 정보이지, 확정된 배송 기록과 같은 뜻은 아니에요.

프레시백 회수 창을 닫으면 회수 완료인가요?

아니에요. 창을 열거나 닫는 것과 회수 완료는 달라요. 쿠팡플렉스에서 실제 회수 완료까지 처리해야 해요. 미회수 처리도 회수 완료와 구분해서, 업무 종료 때 수량을 확인해 주세요.

야간인데 날짜가 오늘과 달라요.

야간 업무는 자정을 넘길 수 있어요. 휴대폰의 오늘 날짜만 보지 말고, 근무표에서 해당 업무가 등록된 날짜를 확인해 주세요. 배송 측정 화면에서 날짜를 직접 바꿀 수 있어요.

‘완료’를 눌렀는데 매출이 안 보여요.

수량 수정 화면의 ‘완료’는 수정한 내용을 검토 화면으로 가져오는 버튼이에요. 최종적으로 매출에 기록하고 종료를 눌렀는지와 저장 결과 안내를 확인해 주세요.

웹과 측정 앱이 같은 계정인지, 기록을 보고 있는 날짜가 맞는지도 확인해 주세요.

다음 업무에는 이것만 기억하세요

  1. 날짜와 구역 확인하기
  2. 쿠팡플렉스 배송목록 화면 열기
  3. 업무 시작 → 필요하면 측정 시작
  4. 차수만 끝났다면 측정 종료
  5. 하루가 끝났다면 수량 확인 → 매출에 기록하고 종료
